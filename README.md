# GLOEUM 글로이음 v2.30.3

기존 해외 바이어 발굴 기능과 Instagram 내부 검색 기반 인플루언서 후보 발굴 기능을 함께 제공하는 Streamlit 개발본입니다.

> 기존 GitHub `main`, Render 운영 서비스, 운영 주소를 그대로 사용합니다. `main` 업로드 후 Render가 자동배포합니다.

## v2.30.3 Apify Search Actor 시간초과 복구

- `HTTP 400` 응답 안에 `status: TIMED-OUT`이 포함된 경우를 요청 오류가 아닌 일시적 시간초과로 판별합니다.
- 후보 20개 이하 시험수집은 핵심 검색어 최대 3개, 검색어당 최대 8건으로 시작합니다.
- Search Actor가 시간초과되면 핵심 검색어 1개, 최대 6건으로 자동 축소해 1회 재시도합니다.
- 오류가 발생하면 상태 영역을 자동으로 펼쳐 실제 원인과 다음 조치를 즉시 표시합니다.

## v2.30.2 검색시간·중단 복원 개선

- 후보 10개 시험수집에서 사용자검색 후보가 15개 이상이면 느린 해시태그 게시물 Actor를 생략합니다.
- Apify 동기 호출 제한을 240초에서 120초로 낮춰 장시간 무응답을 줄였습니다.
- 네트워크 시간초과와 HTTP 408·429·5xx 오류는 1회 자동 재시도합니다.
- 후속 프로필 묶음이 일시 실패해도 앞서 성공한 결과를 버리지 않고 나머지를 검토대기로 보존합니다.
- 전체 수집은 330초 상한을 두고 상한 도달 시 부분 결과와 진단문구를 남깁니다.
- 인증·권한·잔액처럼 재시도로 해결되지 않는 오류만 실행을 종료합니다.

## v2.27.0 Apify 원본 프로필 자동검증

- Brave/Tavily는 Instagram 후보 발견에 사용하고, Apify는 발견된 정확한 계정의 공개 프로필 검증에 사용합니다.
- 검색 버튼 한 번으로 후보 계정명이 Apify에 자동 전달됩니다. Apify Console에 계정명을 다시 복사·붙여넣을 필요가 없습니다.

- API 토큰은 `Authorization` 헤더로만 전송하며 URL·로그·Excel에 저장하지 않습니다.
- 베트남 뷰티 40개 골드셋에서 타국가·기업계정 오포함 0건, 반환 계정명 불일치 0건을 확인했습니다.
- Excel 결과와 검토대기 시트에 Apify 판정·계정일치·국가신뢰도·계정유형·분야적합·판정사유를 기록합니다.

## 운영 배포 순서

1. ZIP 내부 파일을 기존 GitHub `main`에 덮어올립니다.
2. API 키는 파일에 넣지 않고 기존 Render 환경변수를 유지합니다.
3. 기존 `kbp-buyer-finder` 서비스의 자동배포 완료와 `Live` 표시를 기다립니다.
4. Instagram 인플루언서 화면에서 `Apify 실제 연결 테스트`를 먼저 실행합니다.
5. 연결 정상 표시와 Apify Runs의 새 실행을 확인합니다.
6. 베트남·뷰티·후보 10개·Apify 원본 자동검증 켬·웹 검색 보강 끔·외부 공개출처 추가 교차검증 끔으로 시험수집합니다.
7. Instagram 원본 프로필과 Excel의 계정명·팔로워·공개 이메일·DM 문구를 검수합니다.
8. 결과가 안정적일 때만 20개, 이후 100개로 확대합니다.

Instagram 후보 발견·자동검증의 필수 환경변수는 `APIFY_TOKEN`입니다. Instagram 화면의 `BRAVE_SEARCH_API_KEY`와 `TAVILY_API_KEY`는 웹 보강을 켤 때만 필요합니다. 기업 바이어 모드의 기존 검색 키 설정은 그대로 유지됩니다.

Render 자동배포는 `On Commit`으로 유지합니다. 기존 운영 주소 `kbp-buyer-finder.onrender.com`은 그대로 유지됩니다.

상세 배포·검수 기준은 `UPDATE_GUIDE_v2.30.3.md`를 참고하십시오.
